## Phase 2 — Guide Content System (Main Growth Lever)
Informative, genuine guides answering specific high-intent questions in Bangladesh, with direct funnels into the relevant tools.

### System Specifications:
- **URL Pattern**: `/guides/<slug>` (with an index page at `/guides`).
- **Layout**: Clean article column reusing the `policy-docs` / dark theme styling, site Header & Footer, EN/BN toggle, mobile responsive.
- **Content per Guide**: 600–900 words bilingual (EN + BN), clear step-by-step instructions, call-to-action buttons directly linking to tools, `Article` JSON-LD schema, self-canonical, and automatic sitemap inclusion.
